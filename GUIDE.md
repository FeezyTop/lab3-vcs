# Пам'ятка розробника
1. Завжди перевіряйте git status перед створенням коміту.
2. Пишіть зрозумілі повідомлення до комітів українською або англійською.
3. Не додавайте тимчасові файли та коди авторизації до репозиторію.
4. Перед створенням pull request виконуйте локальне тестування.
5. Регулярно синхронізуйте локальну гілку main із віддаленою.
